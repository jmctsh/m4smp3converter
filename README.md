# PythonProject4_m4smp3converter
 
# M4S转MP3工具

![封面图片](static/cover.jpg)

一款基于Python的M4S音频文件转MP3工具，提供网页界面和GUI控制窗口。

## 功能特性
- 支持拖放上传M4S文件
- 自动调用FFmpeg进行无损转换
- 网页端自动下载转换后的MP3文件
- 自动清理临时文件

## 使用说明
1. 下载Release中的可执行文件
2. 双击运行 `M4SConverter.exe`
3. 点击 **启动服务** → **打开浏览器**
4. 上传文件并下载转换后的MP3

## 依赖项
- Python 3.8+
- FFmpeg (已集成在项目中)
